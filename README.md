# hethspices-media

Approved Instagram media for **@hethspices** (Heth Spices, homemade masalas, Mumbai), plus the scripts that render it.

- `media/<yyyy-mm>/<batch>/` — final images that Metricool publishes from. Only approved items are added here.
- `plans/` — the schedule for each batch (times, captions, item ids).
- `brand/`, `labels/` — logo and label artwork used in designs.
- `tools/` — render scripts (HTML → Chrome → JPEG). Fonts: `npm install` in `tools/`.

Content is approved by Heth Spices before it is added. Please don't reuse the brand assets.
